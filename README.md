# Foundation Models for Species-Level Categorization in Animal Re-Identification Pipelines

Bachelor’s thesis project focused on evaluating pretrained foundation models for species-level categorization tasks in animal re-identification pipelines.

## Description

This project investigates the use of the pretrained foundation model SAM v3 for two main tasks in wildlife image processing:

1. Filtering non-animal and animal images from datasets.
2. Classifying animal species within an animal re-identification pipeline.

The study evaluates the effectiveness of foundation models in supporting automated wildlife monitoring and reducing manual processing efforts in large-scale image datasets.

## Objectives

- Evaluate the performance of SAM v3 in dataset filtering.
- Analyze the capability of SAM v3 for species classification.
- Explore the use of pretrained foundation models without additional model training.

## Technologies Used

- Python
- Foundation Models (FM)
- Pretrained Foundation Models (PFM)
- SAM v3
- Image processing and classification methods
